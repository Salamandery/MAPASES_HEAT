## Sobre o Projeto | About

**PT-BR:**
> Sistema desktop Java Swing para envio de arquivos CSV via FTP. Desenvolvido para o sistema TI - HEAT MAPASES, permite o envio automatizado de arquivos de dados com interface gráfica intuitiva e sistema de notificações via tray icon.

**EN:**
> Java Swing desktop system for sending CSV files via FTP. Developed for the TI - HEAT MAPASES system, it allows automated sending of data files with an intuitive graphical interface and tray icon notification system.

## ⚙️ Instalação e Execução | Setup & Run

**PT-BR:**
1. **Pré-requisitos:** Java 8+ e NetBeans IDE
2. **Clone o repositório:**
   ```bash
   git clone [repository-url]
   cd MAPASES_HEAT
   ```
3. **Abra no NetBeans:**
   - Abra o NetBeans IDE
   - Selecione "Open Project"
   - Navegue até a pasta do projeto e selecione
4. **Execute o projeto:**
   - Pressione F6 ou clique em "Run Project"
   - O aplicativo será compilado e executado

**EN:**
1. **Prerequisites:** Java 8+ and NetBeans IDE
2. **Clone the repository:**
   ```bash
   git clone [repository-url]
   cd MAPASES_HEAT
   ```
3. **Open in NetBeans:**
   - Open NetBeans IDE
   - Select "Open Project"
   - Navigate to the project folder and select it
4. **Run the project:**
   - Press F6 or click "Run Project"
   - The application will be compiled and executed
